────────────────────────────────────────────────────────────
DUEL SYSTEM DEPTH
────────────────────────────────────────────────────────────

1. Duel Tournaments
   A bracket-style mini-tournament where 4–8 players sign up, get seeded
   by ELO, and play single-elimination rounds. The platform already has
   rooms, ELO, and lobby infrastructure; this would be the crown jewel
   of the duel system.

2. Duel Achievements
   The platform has 19 achievement definitions but none are duel-specific.
   Milestones like "Win 10 duels", "Achieve 1400 ELO", "Win 5 races in a
   row" would motivate competitive play.

3. Duel Spectator Mode
   Players set a duel as Public or Private when issuing the challenge.
   Spectators join the same real-time room in read-only mode and see the
   live word feed, timer, and lives. Spectator emoji reactions (👀 🔥 😬)
   flash briefly on screen for both players. A spectator count is shown
   to both players (e.g. "👁 4 watching"). A "Live Now" section on the
   Duels lobby shows ongoing public duels that friends are in.
   Builds on the existing WebSocket / DuelRoomRegistry infrastructure.

────────────────────────────────────────────────────────────
GROUP VS GROUP CHALLENGES
────────────────────────────────────────────────────────────

4. Huddle Mode (Phase 1)
   Two groups challenge each other to a synchronous game session.
   One designated typist per group; the rest shout answers. Both groups
   start at the same time via the existing mutual-Ready + countdown flow.
   Same puzzle/seed given to both sides. Works for ALL duel games.
   Entry point: "Challenge Another Group" on the Group detail page.
   No new game logic needed — same engine as 1v1 duels.

5. Team Race Mode (Phase 2)
   Every group member joins on their own device. Members play
   simultaneously; answers are pooled and de-duplicated for the team.
   Real-time team score feed shows both groups' aggregate tallies live.
   Works for simultaneous race games: Anagram Solver, No Repeats, Word
   Stack, Letter Pool, Word Maker, Word Split, Word Scramble.
   Design questions to resolve: player cap, score normalisation for
   unequal group sizes, quorum (min members needed to start).

6. Relay Mode (Phase 3)
   Teams rotate which member is the active typist each round — each
   member gets a turn. Works for turn-based games.
   Build after Huddle and Team Race are stable.

NEW DUEL GAMES
────────────────────────────────────────────────────────────

9. Ladder Rush Duel & Ladder Rush: Double Swap Duel
   Turn-based duel format for both Ladder Rush games. Both players share
   a single word chain: Player A enters a word, Player B must respond
   with a valid word that differs by exactly 1 letter (or 2 for Double
   Swap), and so on. The chain is visible to both players at all times.

   Strategic layer: players are incentivised to use obscure words to
   make it as hard as possible for their opponent to form a valid
   next word. This is unique in the duel roster — every other duel
   game tests speed or accuracy; this one rewards vocabulary depth
   and cunning. The dynamic is closer to chess than to a reflex game.

   Design decisions:
   - Starting word: server-assigned randomly at game start (must be
     neutral — neither player picks it to prevent opener advantage).
   - Word length: chosen in the challenge dialog (4, 5, or 6 letters),
     same as how race games expose target/time-limit pickers.
   - Losing condition: can't form a valid word within the 8-second
     turn timer → lose a life. 3 lives lost = game over. Same as all
     existing turn-based duel games.
   - No-repeat rule: a word already in the chain cannot be used again.
   - Format: Turn-Based only (Race format does not apply — the chain
     is shared state so simultaneous play makes no sense).

   Technical notes:
   - The validate-word endpoint already exists and handles dictionary
     lookups, so server-side word checking is covered.
   - The isNLetterDiff function in ladder-rush.tsx uses letter-frequency
     comparison rather than positional comparison. Works correctly in
     the vast majority of cases but worth a close review for edge cases
     with repeated letters before shipping the duel version.
   - Both games can be added to DUEL_TURN_SLUGS in shared/schema.ts
     as new slugs alongside a corresponding duel adapter in the turn
     engine.
