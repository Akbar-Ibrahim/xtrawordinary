================================================================================
  QUIZ MASTER / CREATOR FEATURE
================================================================================

Overview
--------
- Paid-tier feature (Teacher / School plan priority)
- Two sub-modes:
    1. Self-play customisation
         User tunes a game's parameters and plays it themselves.
    2. Quiz Master (creator for others)
         User configures a game session and shares it via a link/code.
         Recipients play the same configured session.
         Creator sees a results dashboard: who played, scores, completion.
- Underlying infrastructure: a named, persistent "configured round" — reuses
  the existing group/round plumbing but adds content-control knobs and a
  simpler shareable-link UI (no group membership required).

--------------------------------------------------------------------------------
Tier 1 — Very high value, natural knobs  (build first — Phase 1)
--------------------------------------------------------------------------------

  Letter Hunt
    Creator controls : which letter(s) to hunt for
    Use case         : teacher targets S, T, R for a phonics lesson

  Letter Frequency
    Creator controls : which letter to count
    Use case         : phonics / spelling pattern drills

  Letter Position
    Creator controls : which letter at which position
    Use case         : "find words where the 3rd letter is E" — spelling practice

  Letter Balance
    Creator controls : letters assigned to each side
    Use case         : tune consonant vs vowel balance, control difficulty

  Letter Pool
    Creator controls : the exact letter pool given to players
    Use case         : control which words are even reachable

  Word Length
    Creator controls : min/max word length, or a fixed target length
    Use case         : Easy (4-letter words only) vs Hard (8+)

  Definition Match
    Creator controls : word theme / category
    Use case         : teacher targets specific vocab topics
                       (science terms, SAT prep, body parts, etc.)

  Word Roots
    Creator controls : which root prefix/suffix to focus on
    Use case         : "today's lesson: words with -RUPT"

  Progressive Reveal
    Creator controls : the target word(s) to reveal
    Use case         : spelling-test mode — teacher picks the word,
                       student guesses letter by letter

--------------------------------------------------------------------------------
Tier 2 — Good value, a few constraints  (build after Tier 1 — Phase 2)
--------------------------------------------------------------------------------

  Word Scramble
    Creator picks specific words to scramble.
    Natural spelling quiz; limit to a small curated list per session.

  Word Ladder
    Creator picks start + end words.
    Themed transformations (CAT → DOG); works with existing par system.

  Anagram Solver
    Creator picks the anagram sets.
    Good for themed vocabulary lists; backend filters by category.

  Word Split
    Creator picks the compound words.
    Themed vocab (body parts, food, animals, etc.)

  Word Stack
    Creator filters by word category or length.
    E.g. restrict to 5-letter words only.

  No Repeats
    Creator constrains which letters are allowed.
    Force players to stay within a specific consonant/vowel set.

  Word Maker
    Creator picks the starting word.
    Controls what words are derivable from it.

  Word Chain
    Creator picks the starting word (+ optional target ending).
    Themed chains — e.g. start from OCEAN, see where players go.

--------------------------------------------------------------------------------
Tier 3 — Limited but useful  (extend later — Phase 3)
--------------------------------------------------------------------------------

  Word Sweep (Guided)
    Already seeded; creator picks a seed that maps to a specific puzzle.

  Ladder Rush / Double
    Creator pins the word-length difficulty tier for the group.

  Shell Words / Deep Shell Words
    Limited — puzzles are pre-computed; possible to filter by theme.

  Word Bloom
    Creator picks the seed word the insertion chain starts from.

  Word Stretch
    Creator picks the seed word players must expand.

--------------------------------------------------------------------------------
Suggested build phases
--------------------------------------------------------------------------------

  Phase 1 : Quiz Master for the 9 Tier-1 games
            + shared-link / results dashboard infrastructure

  Phase 2 : Extend to Tier-2 games as platform matures

  Phase 3 : Tier-3 games + self-play customisation panel


--------------------------------------------------------------------------------
NEAR-TERM: Quiz Mode polish (pending)
--------------------------------------------------------------------------------

  [ ] Quiz lobby variant summary
        Show a human-readable summary of the session config in the play lobby
        before participants click Play.
        Examples: "Letter M · Position 3 · Survival" (Position Master),
                  "Letter F · Classic" (Letter Hunt)
        Covers all 9 supported quiz games. Params already stored in
        quiz_sessions.params JSON — just needs display logic in quiz-play.tsx.

  [ ] Premium / Self-play Custom Mode

        Main new pieces: isPremium flag on user model, "Custom Play" panel

        Games where this intuitively applies:

================================================================================
  REAL-TIME 1-ON-1 DUELS
================================================================================

Overview
--------
- Paid-tier feature (strong social/competitive hook)
- Synchronous play: both players online at the same time
- Two duel formats depending on the game:
    1. Turn-based alternating  — players swap turns with an 8-second clock
    2. Simultaneous race       — same puzzle, both solve independently, first to
                                 hit the target wins
- Distinct from async friend challenges (this is live, not play-later)
- Requires WebSockets infrastructure (not currently in platform — significant addition)

Core mechanic — shared setup (both formats)
-------------------------------------------
1. Player A challenges Player B to a specific game (Friends page or game detail)
2. Player B accepts — both enter the Waiting Room
3. Waiting Room shows both avatars, names, Ready status
4. Each player clicks "Ready"; countdown triggers only when both are ready (3-2-1)
5. Game starts simultaneously for both players

Turn-based format specifics
----------------------------
- 8-second survival clock per turn; timer bar visible to both players at all times
- Submit a valid answer → turn passes to opponent, opponent's timer resets
- Invalid submissions cost 0.5 seconds (anti-spam; does not end your turn)
- Miss the 8-second window → lose a life (3 lives per player — not instant death)
- Lose all 3 lives → lose the match
- While it is the opponent's turn, your input is locked (can't submit)
- Side-by-side word list updated in real time: Your Column | Opponent's Column

Simultaneous race format specifics
------------------------------------
- Same puzzle / same constraints given to both players
- Both solve independently and simultaneously (no turn locking)
- First to reach the target (complete the puzzle, hit a score threshold, or
  exhaust the solution space) wins
- Real-time score/progress feed: both can see each other's running tally

Connection handling (both formats)
------------------------------------
- If a player disconnects: 30-second grace period to reconnect
- After 30 seconds → that player forfeits automatically
- Prevents rage-quitting via connection drop

Post-match summary (both formats)
-----------------------------------
- Full answer list from both players
- Longest word per player
- Total answers submitted per player
- Match duration
- Duel rating change (+/-)

Duel rating (ELO)
-----------------
- Separate duel rating, distinct from main leaderboard scores
- Winning increases duel rank; losing decreases it
- Shown on user profile alongside main stats

Spectator mode
--------------
- Players set a duel as Public (spectators allowed) or Private (no spectators)
  when issuing the challenge; default is opt-in (private unless made public)
- Spectators join the same real-time room in read-only mode
- Spectators see the identical live feed: words appearing, timer bar, lives
- Spectator emoji reactions (👀 🔥 😬) — briefly flash on screen for both players;
  adds atmosphere without being distracting
- Spectator count shown to both players (e.g. "👁 4 watching") — motivating
- Entry point: a "Live Now" section on the Friends page or Duels lobby showing
  ongoing public duels that friends are in

--------------------------------------------------------------------------------
Games with real-time 1-on-1 potential
--------------------------------------------------------------------------------

TURN-BASED ALTERNATING (Tier A — build first)

  Word Chain
    Most natural duel on the platform.
    Each player chains from the last letter of the opponent's word.
    Fail to find a valid chain in 8s → lose a life.
    Shared "used words" list prevents repeating.

  Letter Hunt
    Alternate submitting words containing the target letter.
    Shared used-word list prevents repeats.

  Letter Balance
    Alternate submitting balance-satisfying words.

  Letter Frequency
    Alternate submitting words with a high count of the target letter.
    Shared used-word list.

  Word Length
    Alternate submitting words of the target length.
    Shared used-word list prevents repeats.

  Shell Words — Crack mode
    Given the same boundary letters, alternate typing the inner word.
    Shared used-word list.

SIMULTANEOUS RACE (Tier B — build after Tier A)

  Word Scramble
    Same scrambled word shown to both players simultaneously.
    Race to unscramble / submit valid words. Score or completion decides winner.

  No Repeats
    Same starting constraints. Both solve independently.
    Whoever exhausts more valid words (or hits target) wins.

  Anagram Solver
    Same scrambled letters for both players.
    Race to find the most valid anagrams within the time window.

  Word Stack
    Same stack puzzle. Race to build the tallest valid stack.

  Letter Pool
    Same letter pool. Race to claim the most / highest-scoring words.

  Word Maker
    Same base word. Race to find the most valid derivatives.

  Word Split
    Same compound word set. Race to split the most correctly.

  Definition Match
    Same definition cards. Simultaneous race to match them.
    Rounds-based (best of 5 or 7).

WEAKER FIT — skip for now
  Progressive Reveal, Word Roots, Word Bloom, Word Stretch,
  Word Sweep, Ladder Rush — don't adapt cleanly to live duel format.

--------------------------------------------------------------------------------
Suggested build phases
--------------------------------------------------------------------------------

  Phase 1 : WebSocket infrastructure (rooms, real-time state sync,
            reconnect grace, disconnect forfeit logic)
            Waiting Room UI (avatars, Ready buttons, 3-2-1 countdown)
            Turn-based engine (timer bar, turn lock, 3-lives system)
            Side-by-side word list UI
            Launch with Turn-Based Tier A games

  Phase 2 : Simultaneous race engine
            Launch Tier B games
            Post-match summary screen
            Duel rating / ELO system
            Duel notifications (invite, result)

  Phase 3 : Spectator mode (public/private toggle, emoji reactions,
            spectator count, Live Now lobby)
            Duel history / match replay
            Spectator chat (optional, scoped)

  Note    : Game classifications (turn-based vs race) can be revisited
            when each game is ready to build. The above reflects intent,
            not final spec.



================================================================================
  GROUP VS GROUP CHALLENGES
================================================================================

Overview
--------
- Extension of the Real-Time 1-on-1 Duels system to team play
- Two groups challenge each other to a synchronous game session
- Three play modes depending on context and game type (see below)
- Builds on top of existing Groups infrastructure and the duel WebSocket layer
- Strong party game / classroom / competitive clan use case

Three play modes
----------------

  1. HUDDLE MODE (one typist per group, group decides together)
     - One designated typist per group; the rest of the group shouts answers
     - Both groups start at the same time (same mutual-Ready + countdown flow)
     - Same puzzle / seed given to both groups
     - Works for ALL games — turn-based and race alike
     - Requires no extra infrastructure beyond standard 1v1 duel system
     - Party game energy: same-room groups, classrooms, family game nights

  2. TEAM RACE MODE (every member plays on their own device)
     - Each group member joins independently on their own device
     - Members play simultaneously; answers are pooled for the team (de-duplicated)
     - Works for SIMULTANEOUS RACE games only (turn-based doesn't fit)
     - Real-time team score feed: both groups see each other's aggregate tally
     - Members coordinate externally (voice call, same room) — platform doesn't
       need to provide a side-channel; lean on WhatsApp/Discord

  3. RELAY MODE (future — teams rotate typists per round)
     - Teams rotate which member is the active typist, round by round
     - Each member gets a turn; passing the "keyboard" within the team
     - Works for turn-based games
     - Build after Huddle and Team Race are stable

Key design problems to solve
------------------------------

  Unequal group sizes
    A 6-member group vs a 2-member group is unfair in Team Race mode.
    Options (decide at build time):
      - Cap participation: each group nominates N players (e.g. max 5)
      - Score normalisation: team score ÷ number of active members
      - Minimum/maximum player count set by the challenge creator

  Quorum — does everyone need to be ready?
    Don't hold the match hostage if one member hasn't joined.
    Suggestion: a minimum quorum (e.g. at least 2 members per group) must
    click Ready before the countdown is allowed to trigger.
    Challenge creator sets the quorum when issuing the challenge.

  Spectators
    Same spectator model as 1v1 duels: public/private toggle, read-only feed,
    emoji reactions, spectator count visible to both groups.
    Particularly compelling for group challenges — could draw a small crowd.

--------------------------------------------------------------------------------
Games with group vs group potential
--------------------------------------------------------------------------------

HUDDLE MODE — all games that support 1v1 duels work here
  (Same list as Real-Time 1-on-1 Duels → Tier A and Tier B above)
  No additional game work needed; it's the same game, different account type.

TEAM RACE MODE — simultaneous race games only

  Anagram Solver
    Combined team pool of anagrams found (de-duplicated).
    Teams coordinate to avoid overlap — each member claims different words.

  No Repeats
    Each member contributes words to the team pool.
    Shared letter-exclusion constraint applies across ALL team members —
    forces internal coordination (can't repeat a letter anyone on the team used).

  Word Stack
    Each member adds to the team's shared stack independently.

  Letter Pool
    Members claim words from a shared letter pool; team exhausts it faster.

  Word Maker
    Combined derivations from the same base word (de-duplicated).

  Word Split
    Combined compound words found (de-duplicated).

  Word Scramble
    Best individual time counts for the team, or average of top N members.

--------------------------------------------------------------------------------
Suggested build phases
--------------------------------------------------------------------------------

  Phase 1 : Huddle Mode
            Extend the 1v1 duel challenge flow to accept a group as a challenger
            or challengee. One account per group plays — no new game logic needed.
            Group challenge entry point: Group detail page ("Challenge Another Group")

  Phase 2 : Team Race Mode
            Multi-device join flow (all members join the same team room)
            Answer aggregation / de-duplication engine
            Team score feed (real-time aggregate visible to both groups)
            Fairness controls (player cap, score normalisation, quorum setting)

  Phase 3 : Relay Mode
            Spectator mode for group challenges
            Group challenge history and leaderboard
